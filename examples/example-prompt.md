# Example Prompt

Use this when you want a standard episode request:

```text
Use $titi-story to write a new TiTi story for the core word LIGHT.
```

You can also add small creative constraints without changing the fixed template:

```text
Use $titi-story to write a new TiTi story for the core word RAIN.
Keep it at night, make the wish lantern help a small friend, and end with a funny twist.
```

## Good Prompt Pattern

The cleanest prompt shape is:

```text
Use $titi-story to write a new TiTi story for the core word <WORD>.
Optional constraints...
```

## Constraints That Fit Well

- time of day
- location
- emotional tone
- helper target
- tiny conflict
- desired funny ending direction

## Constraints That Usually Do Not Belong In The Skill Prompt

- changing the shot count
- removing the learning intro
- switching away from bilingual output
- turning it into a music-led video

Those are structural changes, not normal episode requests.
