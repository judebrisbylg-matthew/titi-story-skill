# Workflow

This skill is designed to sit inside a larger production pipeline.

## Full Pipeline

1. Choose a core word
2. Generate a story script with `$titi-story`
3. Extract the 12-shot storyboard
4. Generate image prompts for each shot
5. Produce visuals
6. Record bilingual voice lines
7. Add sound effects only
8. Edit into final short-form episode

## Input

The skill works best when the user provides:

- one core word
- optional emotional direction
- optional setting adjustment
- optional story constraint

Example:

```text
Use $titi-story to write a TiTi story for the word LIGHT.
```

## Output

The output is a structured script, not a loose concept.

That means the user can immediately reuse it for:

- storyboard cards
- art prompting
- voice recording
- post-production planning

## Why Structure Matters

For serialized children's content, instability creates friction:

- editors lose timing consistency
- image prompting becomes messy
- language repetition becomes uneven
- educational pacing becomes less reliable

This skill reduces that friction by making each script predictable in shape while still allowing new story content.
