# Features

## 1. Fixed Template Output

The skill always writes in the same `制作模版3.0` structure:

- protagonist block
- style block
- story summary
- character block
- learning word intro sequence
- word treatment notes
- main 12-shot storyboard
- dialogue summary
- smart English matching line

This removes formatting drift between episodes.

## 2. Fixed Character Lock

The skill keeps TiTi visually and narratively stable:

- same wood puppet identity
- same costume system
- same tone
- same emotional range
- same night-scene variant when relevant

## 3. Built-in Educational Structure

Each story is not just narrative. It also includes:

- a dedicated word-learning intro
- repeated English word exposure
- short A1-level phrases
- bilingual reinforcement

## 4. Built-in Magic System

The skill understands the `愿望灯` rules:

- kind wish only
- help others only
- warm small miracles only
- TiTi still has to act

This helps keep stories coherent across a long-running series.

## 5. Production-Friendly Shot Writing

The skill writes shots in a way that is usable for:

- storyboard planning
- scene-by-scene image generation
- dubbing
- editing timeline layout

## 6. Audio Discipline

The skill preserves the no-background-music rule:

- voice
- effects
- simple sound cues

It avoids embedding music-heavy directions that do not fit the user’s workflow.

## 7. Child-Friendly Ending Rhythm

Each story is designed to end with a light, funny twist so the emotional finish feels memorable and playful.
