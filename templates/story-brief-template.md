# Story Brief Template

Use this brief before calling the skill when you want slightly more control over the episode.

## Story Brief

- Core word:
- Time of day:
- Location:
- Who needs help:
- Wish lantern trigger:
- Emotional arc:
- Funny ending idea:
- Optional visual note:
- Optional dialogue note:

## Example

- Core word: LIGHT
- Time of day: night
- Location: forest path
- Who needs help: a lost little hedgehog
- Wish lantern trigger: TiTi wants to help it find home
- Emotional arc: worry -> hope -> action -> relief -> laughter
- Funny ending idea: the hedgehog thinks the lantern is a tiny moon
- Optional visual note: keep the glow warm and gentle
- Optional dialogue note: keep sentences very short
